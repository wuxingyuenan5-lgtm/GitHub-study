# H - 实盘交易工具

> 对接券商/交易所的实盘下单工具，覆盖A股、期货和加密货币三个市场。

---

## 1. easytrader

| 属性 | 详情 |
|------|------|
| GitHub | [shidenggui/easytrader](https://github.com/shidenggui/easytrader) |
| Stars | 8.5k |
| 许可证 | MIT |

**核心功能**：通过**模拟鼠标点击**对接券商客户端（同花顺/招商证券/银河等）实现自动下单。不需要券商API，直接操作客户端GUI界面完成买卖操作。

✅ 优点：
- 8.5k Stars，中文量化社区使用广泛
- **不需要券商API**，绕过了券商对API的严格限制
- 支持多家券商客户端（同花顺/招商/银河等）
- MIT许可证，商业友好
- 配套easyquotation获取实时行情

❌ 缺点：
- ⚠️ **核心风险**：模拟鼠标点击依赖券商客户端UI，客户端升级→脚本失效，维护成本高
- 操作延迟较大（模拟点击+界面响应），不适合高频/低延迟场景
- 客户端必须保持前台运行，影响日常使用
- 券商可能检测异常操作行为，存在合规风险
- 长期维护不确定，作者更新频率已放缓

适用场景：**A股低频自动化交易**，适合日内级别的策略执行，不适合秒级/毫秒级场景。适合无法获取券商API的个人量化者。

## 2. tqsdk

| 属性 | 详情 |
|------|------|
| GitHub | [shinnytech/tqsdk-python](https://github.com/shinnytech/tqsdk-python) |
| Stars | 4.9k |
| 许可证 | MIT |

**核心功能**：**期货量化专用**SDK，提供实时行情、历史数据、实盘交易一体化支持。天勤量化官方出品，专注于期货市场（商品期货/金融期货）。

✅ 优点：
- **期货市场专用**，行情/数据/交易全链路覆盖，无需拼凑多个工具
- 实时行情推送质量高，Tick级数据支持
- MIT许可证
- 官方团队维护，稳定性有保障
- Python接口，API设计清晰易用
- 提供完整的模拟盘环境，可先验证后实盘

❌ 缺点：
- 仅支持期货市场，不支持股票/加密货币
- 实盘交易需通过天勤指定的期货公司通道
- 免费版有功能限制（如并发连接数），付费版价格较高
- 高频交易场景下延迟可能不够低

适用场景：**期货量化交易**，适合商品期货/金融期货的策略开发与实盘执行；期货Tick级数据获取。

## 3. freqtrade ⚠️ GPL-3.0

| 属性 | 详情 |
|------|------|
| GitHub | [freqtrade/freqtrade](https://github.com/freqtrade/freqtrade) |
| Stars | 22.7k |
| 许可证 | ⚠️ GPL-3.0 |

**核心功能**：**加密货币交易机器人**，支持60+交易所（Binance/OKX/Bybit等），提供回测+策略优化+实盘交易+Telegram控制+Web界面完整工具链。策略用Python编写，社区策略模板丰富。

✅ 优点：
- **加密货币量化生态最成熟**：22.7k Stars，社区策略库庞大
- 60+交易所对接，覆盖主流加密货币平台
- 回测+策略优化+实盘全链路，一站式解决方案
- Telegram Bot控制，随时随地监控和管理
- Web UI界面直观，策略管理方便
- 策略用Python编写，开发门槛低
- 社区活跃，大量策略模板和讨论

❌ 缺点：
- ⚠️ **GPL-3.0许可证**：修改后必须开源，商业使用受限
- 仅支持加密货币，不支持股票/期货
- 加密货币市场高波动，策略稳定性难保证
- 过度优化（Hyperopt）风险大，回测≠实盘
- 部分交易所API变更频繁，需要及时更新适配

适用场景：**加密货币量化交易**，适合加密货币策略开发与自动化执行；多交易所套利；个人量化交易者的入门实盘工具。

> ⚠️ GPL-3.0 提醒：如果你对freqtrade进行了修改并分发，必须以GPL-3.0开源发布。商业使用需仔细评估许可证约束。

| 项目 | Stars | 许可证 | 市场覆盖 | 推荐度 | 关键词 |

| easytrader | 8.5k | MIT | A股 | ⭐ | 模拟点击、绕过API限制 |
