## 核心功能

FinClaw 是上财推出的「金融智能体龙虾」生态，以五种金融机构形态覆盖金融全场景的AI Skills：

### 五种龙虾形态

| 形态 | 金融领域 | 核心Skills方向 |
|------|---------|--------------|
| 🦞 **银行龙虾** | 商业银行 | 信贷评估、反洗钱、资产负债管理、零售银行 |
| 🦞 **证券龙虾** | 证券投资 | 研报分析、量化策略、投资建议、合规审查 |
| 🦞 **保险龙虾** | 保险业 | 精算评估、理赔审核、产品设计、风险定价 |
| 🦞 **基金龙虾** | 基金管理 | 组合分析、归因分析、绩效评估、持仓透视 |
| 🦞 **期货龙虾** | 期货衍生品 | 套利策略、保证金管理、交割分析、波动率交易 |

### 核心特性

- **1000+金融专属Skills**：覆盖从银行到期货的金融全产业链，每个Skill对应一个具体的金融任务
- **全量免费**：不同于多数大模型项目的部分开源，FinClaw承诺全部Skills免费开放
- **知识驱动**：基于金融专业知识和业务逻辑构建Skills，非简单的模型调参
- **政府背书**：上海市经信委专项支持，代表了产学研结合的官方认可
