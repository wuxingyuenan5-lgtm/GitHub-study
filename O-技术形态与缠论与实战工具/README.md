## 2. Sequoia — 海龟交易+缠论买点+技术形态自动选股 🧊 冷门

### 核心属性

| 属性 | 内容 |
|------|------|
| **GitHub** | [xoyojo/Sequoia](https://github.com/xoyojo/Sequoia) |
| **Stars** | ~200 |
| **许可证** | 未标明 |

### 核心功能

Sequoia 是一个面向A股的自动选股系统，融合了经典海龟交易法则与缠论中的买点识别：

- **海龟交易法则**：Donchian通道突破信号 + ATR动态仓位管理
- **缠中说禅牛市买点**：一买/二买/三买的识别与筛选
- **技术形态识别**：头肩底/双底/三角形突破/旗形等经典形态
- **数据接口**：基于AKShare免费获取A股日线行情
- **技术指标**：TA-Lib计算MACD/RSI/KDJ/布林带等技术指标
- **自动扫描**：定期全市场扫描，输出符合条件的候选股票

### 优点

- ✅ 海龟+缠论+技术形态多策略融合，覆盖面广
- ✅ AKShare免费数据源，零成本运行
- ✅ 自动扫描筛选，减少人工盯盘负担

### 缺点

- ❌ 策略融合的权重和筛选逻辑不够透明
- ❌ 缠论实现质量不如 chan.py 专业
- ❌ 文档较少，参数调优依赖经验
- ❌ 缺少风险评估和仓位管理模块

### 适用场景

- A股中短线选股的辅助参考
- 学习海龟交易和缠论买卖点的实现方式
- 需要一个简单的自动选股工具

## 3. Z哥战法Python实现 — 5种战法+短线/长线约束 🧊 极冷门实战

### 核心属性

| 属性 | 内容 |
|------|------|
| **GitHub** | [SebastienZh/StockTradebyZ](https://github.com/SebastienZh/StockTradebyZ) |
| **Stars** | 较少（极冷门项目） |
| **许可证** | 未标明 |

### 核心功能

该项目将特定投资博主的5种战法用Python实现，是一个极具个人风格的实战工具：

- **5种战法**：

  | 战法名称 | 核心逻辑 |
  |---------|---------|
  | **少妇战法（BBIKDJ）** | BBI多空指标 + KDJ超卖反弹 |
  | **SuperB1战法** | 特定均线突破信号 |
  | **补票战法** | 强势股回调后的二次介入 |
  | **填坑战法** | 跌幅恢复后的反弹交易 |
  | **上穿60放量** | 放量突破60日均线 |

- **当日过滤**：统一当日内对5种战法进行过滤，避免重复触发
- **短线/长线约束**：知行短线和知行长线分别设置持仓约束条件
- **数据源**：Tushare日线前复权（qfq）数据

### 优点

- ✅ 5种战法设计各有特色，有多样化的策略覆盖
- ✅ 当日统一过滤避免了过度交易
- ✅ 期货/长线分类约束符合实际交易习惯

### 缺点

- ❌ 极其冷门，代码质量和策略有效性未经验证
- ❌ 战法来源个人主观，缺少理论基础
- ❌ Tushare需要积分，非免费方案
- ❌ 可能存在过度拟合个人经验的风险
- ❌ 缺少系统性的回测报告

### 适用场景

- 想要快速实现特定战法/策略的量化开发者
- 学习不同战法Python实现的参考代码

## 4. AStock Analyzer — 五维涨停预测+游资跟踪 🧊 冷门实战

### 核心属性

| 属性 | 内容 |
|------|------|
| **GitHub** | [hacker4257/astock_analyzer](https://github.com/hacker4257/astock_analyzer) |
| **Stars** | <50 |
| **许可证** | **MIT** |

### 核心功能

AStock Analyzer 是一个功能丰富的A股分析系统，以「五维涨停预测」和游资跟踪为特色：

- **五维涨停预测**：
  - 技术维：突破形态、均线多头排列
  - 资金维：主力资金流向、大单动向
  - 消息维：利好公告、热点事件
  - 基本面维：PE/ROE/营收增长
  - 情绪维：市场热度、涨停板情绪
- **游资跟踪**：龙虎榜席位分析，追踪知名游资买卖动向
- **智能选股**：多因子综合评分选股
- **买入信号**：基于多维度条件触发的买入提醒
- **风险预警**：跌停风险、退市风险、大股东减持风险
- **双界面**：
  - Streamlit Web界面（快速部署）
  - FastAPI REST API（程序化调用）
- **多数据源**：AKShare / efinance / baostock 三选一

### 优点

- ✅ 五维分析框架全面，覆盖了从技术面到情绪的多个维度
- ✅ 游资跟踪（龙虎榜分析）是独特功能，其他项目罕见
- ✅ Streamlit+FastAPI双界面适应不同使用场景
- ✅ MIT许可证，商业友好
- ✅ 多数据源可选，降低单一数据源依赖风险

### 缺点

- ❌ Stars较少，代码完善度未知
- ❌ 「五维」打分权重未公开透明化
- ❌ 涨停预测准确率缺少系统性的验证报告
- ❌ 龙虎榜数据时效性依赖数据源
- ❌ 部分功能（消息维/情绪维）依赖爬虫稳定性

### 适��场景

- A股短线交易者寻找涨停候选标的
- 游资动向跟踪和市场情绪监控
- 需要Web界面操作的多因子选股工具
