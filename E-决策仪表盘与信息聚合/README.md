## 17. daily_stock_analysis ⭐ 强烈推荐

| 属性 | 详情 |
|------|------|
| **GitHub** | https://github.com/ZhuLinsen/daily_stock_analysis |
| **Stars** | **8k+** |
| **许可证** | MIT ✅ |
| **语言** | Python |

### 核心功能
- **LLM驱动的A股/港股/美股智能分析器**
- 每日自动分析自选股，推送"决策仪表盘"到企微/飞书/Telegram
- 一句话核心结论 + 买卖点位 + 操作检查清单
- 支持 DeepSeek/通义千问/Gemini/Claude 等国产模型
- **GitHub Actions 定时运行**：零成本，无需服务器
- 数据源：AKShare/efinance免费获取

### ✅ 优点
1. **MIT许可证**：完全自由
2. **零成本运行**：GitHub Actions免费，DeepSeek API也极便宜
3. **自动推送**：每天收盘后自动推到企微/飞书/Telegram，上班族友好
4. **一句话结论**：不是冗长报告，而是明确的买卖建议+检查清单
5. **国产模型友好**：DeepSeek/通义千问直接可用
6. **A股原生**：专为A股/港股/美股设计

### ❌ 缺点
1. **分析深度有限**：一句话结论模式，不适合深度研究
2. **依赖免费数据源**：AKShare数据质量不如Wind/Choice
3. **没有回测验证**：建议是否有效没有系统验证
4. **GitHub Actions限制**：运行时间有限（6小时），复杂分析可能超时
5. **只适合日频**：不支持日内分析

### 适用场景
- 上班族想每天收盘后自动收到持仓分析推送
- 日常选股辅助（不需要深度报告，只要方向判断）
- 最省钱的AI选股方案
