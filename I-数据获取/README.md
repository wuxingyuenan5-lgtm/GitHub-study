# I - 数据获取

> 量化交易的数据基石，覆盖A股/全球市场/财务指标/前端行情/学术论文的完整数据生态。

---

## 1. AKShare ⭐

| 属性 | 详情 |
|------|------|
| GitHub | [akfamily/akshare](https://github.com/akfamily/akshare) |
| Stars | ~9k |
| 许可证 | MIT |

**核心功能**：A股/港股/期货/宏观/加密货币数据**免费全覆盖**。Python接口，数据源覆盖东方财富/同花顺/新浪/腾讯等多家平台，单一API调用即可获取行情/财务/资金流/板块/宏观等全维度数据。

✅ 优点：
- **覆盖面最广**：A股/港股/期货/宏观/加密货币，几乎无所不包
- ~9k Stars，中文量化社区使用率最高
- MIT许可证，商业友好
- 数据源多平台融合，单一接口获取多源数据
- 更新频繁，跟随市场变化及时
- 纯Python，安装简单（pip install akshare）

❌ 缺点：
- 数据来自爬虫，数据源变动时接口可能临时失效
- 无官方数据质量承诺，需自行校验
- 数据量大时爬取速度受限，不适合高频实时场景
- 接口命名规则不统一，学习成本较高
- 部分接口返回格式不稳定，版本升级可能breaking change

适用场景：**A股量化数据首选**，适合因子研究/回测数据获取/宏观分析等绝大多数量化数据需求。

## 2. adata

| 属性 | 详情 |
|------|------|
| GitHub | [1nchaos/adata](https://github.com/1nchaos/adata) |
| Stars | 5k |
| 许可证 | MIT |

**核心功能**：专注**A股**的免费量化交易数据库，多数据源融合（东方财富/同花顺/新浪等），提供行情/财务/资金/板块等A股专用数据。

✅ 优点：
- A股专注，接口设计更贴合A股使用习惯
- 5k Stars，有一定社区基础
- MIT许可证
- 多数据源融合，提升数据覆盖和稳定性
- 数据分类清晰，A股维度覆盖完整

❌ 缺点：
- 仅覆盖A股，不支持港股/美股/期货/加密货币
- 数据源同样依赖爬虫，稳定性问题同AKShare
- 社区活跃度低于AKShare
- 文档和示例相对较少

适用场景：**纯A股量化数据需求**，适合只做A股不需要跨市场数据的场景；可作为AKShare的A股数据备选源。

## 3. FinanceToolkit 🧊 ⭐ 推荐关注

| 属性 | 详情 |
|------|------|
| GitHub | [JerBouma/FinanceToolkit](https://github.com/JerBouma/FinanceToolkit) |
| Stars | 5.2k |
| 许可证 | MIT |

**核心功能**：**130+财务指标计算**，全球市场覆盖。不仅能获取数据，更能直接计算DCF/EVA/WACC/Altman Z-Score等专业财务指标。还支持**MCP Server**模式，可直接嵌入WorkBuddy等AI工具使用！

✅ 优点：
- **130+财务指标**直接计算，不只是数据获取，更是财务分析工具
- 全球市场覆盖（美股/欧股/新兴市场等），A股以外的市场数据补充
- **MCP Server支持** — 可直接嵌入AI Agent使用，这是杀手级特性
- MIT许可证
- 代码质量高，结构清晰，文档专业
- 与FinanceDatabase配合，可获取大量公司基础数据

❌ 缺点：
- 🧊 冷门项目（相对AKShare而言），中文社区使用较少
- A股数据覆盖不如AKShare/adata深入
- 财务指标计算需要一定财务知识背景
- MCP Server功能尚属新特性，稳定性待验证

适用场景：**全球市场财务分析**；AI Agent集成场景（MCP Server）；需要专业财务指标计算（DCF/估值/信用评分）的投研工作。

## 4. stock-sdk 🧊 冷门前端 ⭐ 推荐关注

| 属性 | 详情 |
|------|------|
| GitHub | [chengzp/stock-sdk](https://github.com/chengzp/stock-sdk) |
| Stars | ~940 |
| 许可证 | MIT |

**核心功能**：**前端TypeScript行情SDK**，零依赖，浏览器+Node.js双支持。覆盖A股/港股/美股/基金/期货/期权实时行情+K线+技术指标。特色数据：龙虎榜/大宗交易/融资融券/涨停板池/盘口异动/北向资金。也有**MCP Server (stock-sdk-mcp)**。

✅ 优点：
- **前端行情SDK** — 独特定位，量化圈罕见的前端侧数据方案
- 零依赖，轻量级，嵌入方便
- 浏览器+Node.js双支持，灵活度高
- 特色数据丰富：龙虎榜/大宗交易/融资融券/北向资金等
- **MCP Server支持** — 可嵌入AI Agent
- MIT许可证
- TypeScript类型安全

❌ 缺点：
- 🧊 冷门项目，社区和使用案例较少
- 仅提供行情数据，不包含财务/基本面数据
- 前端场景数据实时性受浏览器环境限制
- 数据源稳定性需自行验证
- 文档和示例有待完善

适用场景：**量化前端应用开发**（行情展示页面/交易看板）；AI Agent行情数据集成（MCP Server）；需要龙虎榜/北向资金等特色数据的场景。

## 5. stock-top-papers 🧊 冷门学术资源

| 属性 | 详情 |
|------|------|
| GitHub | [RolfLobo/stock-top-papers](https://github.com/RolfLobo/stock-top-papers) |
| Stars | ~200 |
| 许可证 | — |

**核心功能**：股价预测+量化交易**顶会论文集合**（KDD/WWW/AAAI/NeurIPS/ACL等），每篇论文附Paper链接+Code链接，按**时间/任务/模型/方法**四维度分类整理。

✅ 优点：
- **论文索引价值高** — 系统性整理顶会论文，省去自己搜索的时间
- 每篇论文附Paper+Code双链接，直接获取原文和实现
- 四维度分类（时间/任务/模型/方法），查找方便
- 持续更新，紧跟最新顶会成果

❌ 缺点：
- 🧊 极冷门项目，使用者少
- 仅为论文索引，无代码/数据/工具可直接使用
- 论文分类体系可能不完全覆盖所有研究方向
- 需要自行评估论文质量和代码可用性

适用场景：**量化研究文献调研**，适合需要系统性了解股价预测/量化交易领域最新学术进展的研究者；论文选题和方法参考。

## 分类总结

| 项目 | Stars | 许可证 | 推荐度 | 关键词 |
|------|-------|--------|--------|--------|
| AKShare | ~9k | MIT | ⭐ | A股全覆盖、社区最广 |
| adata | 5k | MIT | ⭐ | A股专注、多源融合 |
| FinanceToolkit | 5.2k | MIT | 🧊⭐ | 130+财务指标、全球市场、MCP Server |

**A股数据首选**：AKShare — 覆盖面最广，社区最大，绝大多数A股数据需求一站解决。

**财务分析/全球市场**：FinanceToolkit — 130+指标直接计算+MCP Server集成，投研场景的最佳补充。

**前端行情/特色数据**：stock-sdk — 唯一的前端侧行情方案+MCP Server，适合前端量化应用和AI Agent集成。

**学术研究**：stock-top-papers — 论文索引工具，省去文献搜索时间。
