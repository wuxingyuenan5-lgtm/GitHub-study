## 1. FinSight（玉兰·融观）🔥 冠军项目

| 属性 | 详情 |
|------|------|
| **GitHub** | https://github.com/RUC-NLPIR/FinSight |
| **Stars** | ~300 |
| **许可证** | GPL-3.0 ⚠️ 传染性 |
| **团队** | 中国人民大学高瓴AI学院窦志成教授NLPIR实验室 |
| **荣誉** | AFAC2025赛题四冠军（1289队第一名） |
| **论文** | ArXiv 2510.16844 |
| **Python** | 3.10+ |

### 核心功能
- **一键生成2万字+专业研报**：输入股票代码，自动采集→分析→撰写→输出DOCX/PDF
- **CAVM变量内存架构**：所有Agent共享统一变量空间，代码执行结果直接存入变量，比纯prompt方案更可靠可复现
- **VLM图表评审循环**：LLM生成图表→VLM视觉模型评估质量→反馈修改→最多迭代3次
- **57个金融/宏观/行业工具**：akshare+efinance免费数据源，覆盖A股/港股/美股/宏观经济
- **4种研究类型**：公司研究/宏观分析/行业研究/通用深度研究
- **Web Demo界面**：React+Ant Design控制台，实时监控执行进度

### 技术架构
三阶段流水线 + 优先级调度：
1. **DataCollector** → 路径采集57个工具获取结构化/非结构化数据
2. **DeepSearchAgent** → 多跳网络搜索+爬虫抓取最新资讯
3. **DataAnalyzer** → CAVM代码驱动分析，生成图表+VLM评审
4. **ReportGenerator** → 大纲生成(初版→批判→修改3轮) → 分章节撰写 → 最终润色

### ✅ 优点
1. **架构设计清晰**：三阶段流水线+优先级调度，Agent职责分离做得好，比学术demo更像产品
2. **CAVM变量内存机制是真正创新**：代码执行结果存入共享变量空间，后续Agent直接引用，比prompt链路更可靠
3. **VLM图表评审解决了实际问题**：用视觉模型评估图表质量，反馈修改迭代，这个闭环思路实用
4. **57个金融工具覆盖面广**：从公司财报到宏观经济再到行业PMI，数据维度很全
5. **比赛冠军验证**：1289支队伍第一名，不是纯论文玩具项目
6. **三层可控定制**：大纲模板→Agent Prompt→配置参数，报告思路可定制

### ❌ 缺点
1. **对LLM质量高度依赖**：推理质量完全取决于底层模型，用弱模型会出幻觉直接写入报告
2. **搜索引擎依赖是硬伤**：必须用Serper/Bing/Google等外部搜索API，国内用户不便
3. **单次报告成本不低**：至少50-100次API调用，DeepSeek约¥5-10/篇，GPT-4o约¥30-50/篇
4. **缺少事实核查环节**：没有独立Fact-Check Agent交叉验证数据和结论准确性
5. **GPL-3.0传染性**：商业使用受限，修改后分发必须开源
6. **报告模板较固定**：只有4种大纲类型，自定义空间有限
7. **后端启动很慢**：导入57个工具模块约需1分钟

### 适用场景
- 研究机构需要批量生产专业研报
- 个人投资者想一键生成某公司的深度报告
- 学习多Agent金融系统架构设计

### 运行要求
- Python 3.10+, .venv独立环境
- LLM API Key（DeepSeek/OpenRouter均可）
- VLM API Key（硅基流动/OpenRouter）
- Embedding API Key
- Search API Key（Serper/Bing/Bocha）
- Pandoc（DOCX/PDF输出）
