# U. 其他关注清单

> 你 GitHub Stars 中收藏的通用 AI、编程、生产力、学习资源类项目。它们不直接属于二级市场分析/交易工具，但可能提升你的 AI 工作流、编程效率或知识广度，因此单独整理在此。

---

## 为什么这些项目没进主分类

本仓库的主索引聚焦 **二级市场分析、交易、量化、投研** 相关工具。以下项目虽然被你收藏，但主要用途是：

- 通用 AI 编程辅助（Claude Code / Codex / Cursor Skills）
- Vibe Coding / AI 结对编程教程
- 前端/UI 组件、网站克隆模板
- 一人企业/自媒体/区块链安全等知识资源
- 通用 API 列表、深度学习笔记

如果后续你的需求扩展到"用 AI 辅助金融软件开发"或"搭建量化投研的个人工作流"，这些项目会很有价值。
