## 2. ai-quant-book ⭐

| 属性 | 详情 |
|------|------|
| **GitHub** | https://github.com/waylandzhang/ai-quant-book |
| **Stars** | 未显示 |

| **作者** | Wayland Zhang |
| **特点** | 《AI量化交易从0到1》中英双语开源书 |

### 核心内容
- 5部分、22课、30篇背景知识、4篇附录
- Part 1：快速体验（量化全景图、多智能体直觉）
- Part 2：量化基础（市场、统计、策略、数据、回测）
- Part 3：机器学习（监督学习、从模型到Agent）
- Part 4：多智能体（架构、Regime、LLM、风控）
- Part 5：生产实战（成本、执行、运维、实战）
- 中文完整版：`manuscript/cn`
- 英文完整版：`manuscript/en`

### ✅ 优点
1. **系统性强**：从0到1覆盖量化交易全流程
2. **中英双语**：中英文读者都可用
3. **多智能体架构**：紧跟AI Agent趋势
4. **生产实战导向**：不只是回测，还讲成本、执行、运维
5. **免费开源**：可直接阅读学习

### ❌ 缺点
1. **CC BY-NC-SA 4.0许可证**：仅非商业用途，商业使用受限
2. **是书籍而非代码**：需要配合其他工具实践
3. **部分内容需要一定基础**：统计、金融常识有帮助
4. **更新频率不确定**：开源书籍依赖作者持续维护

### 适用场景
- 量化入门系统学习
- 想了解如何用多智能体架构做量化交易
- 从开发转向量化交易的研究者
