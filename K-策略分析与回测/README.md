## 1. Qbot — 智能交易策略+回测+自动调仓量化机器人 🔥

### 核心属性

| 属性 | 内容 |
|------|------|
| **GitHub** | [UFund-Me/Qbot](https://github.com/UFund-Me/Qbot) |
| **Stars** | ~11,400 |
| **许可证** | MIT |

### 核心功能

Qbot 是一个多引擎集成的全自动量化交易系统，通过统一的策略接口整合了多个主流回测/交易引擎：

- **多引擎集成**：同时支持 vnpy、backtrader、qlib、JoinQuant（聚宽）等多套回测引擎，用户可按需切换
- **智能选股**：内置多种选股因子和机器学习模型选股策略
- **自动交易**：支持对接多家券商（华泰、国信等）实现程序化下单
- **GUI界面**：PyQt5开发的桌面端交互界面，降低使用门槛
- **策略库**：内置MACD、双均线、RSI、布林带等经典策略模板
- **风险监控**：持仓状态实时监控与风控报警

### 优点

- ✅ 多引擎集成是核心亮点，一套策略可跨引擎验证，避免单一引擎回测偏差
- ✅ 从选股→回测→模拟→实盘形成完整闭环
- ✅ 有GUI界面，非程序员也能操作
- ✅ MIT许可证，商业使用友好
- ✅ 社区活跃，Stars破万

### 缺点

- ❌ 集成过多引擎导致依赖复杂，安装配置容易出问题
- ❌ GUI界面稳定性一般，长时间运行偶有崩溃
- ❌ 文档不够系统，部分功能缺少详细说明
- ❌ 各引擎版本更新后可能出现兼容性问题
- ❌ 自定义策略门槛较高，需理解各引擎的API差异

### 适用场景

- 想快速搭建「选股→回测→交易」全流程的个人量化交易者
- 在多个回测引擎间对比验证策略，避免单引擎偏差
- 需要GUI操作界面、不想写代码的投资爱好者

## 2. abu量化 — 轻量级语义化策略框架 🔥 ⚠️ GPL-3.0

### 核心属性

| 属性 | 内容 |
|------|------|
| **GitHub** | [bbfamily/abu](https://github.com/bbfamily/abu) |
| **Stars** | ~13,700 |
| **许可证** | **GPL-3.0** ⚠️（传染性许可证，商业使用需注意） |

### 核心功能

abu量化是国内最具影响力的个人量化开源项目之一，以「语义化策略编写」和内置缠论/波浪理论著称：

- **��义化策略**：买什么（买入因子）→什么时候卖（卖出因子）→怎么管钱（资金管理因子），用自然语言逻辑编写策略
- **内置缠论**：完整的缠中说禅理论实现，包括分型、笔、线段、中枢、买卖点
- **内置波浪理论**：艾略特波浪形态识别与标注
- **经典技术指标**：MACD、KDJ、RSI、布林带、ATR等全覆盖
- **A股适配**：内置A股交易规则（T+1、涨跌停、印花税等）
- **回测引擎**：事件驱动模拟撮合，包含滑点和手续费
- **机器学习择时**：SVM/决策树在关键买卖点辅助决策

### 优点

- ✅ 语义化策略设计优秀，策略代码可读性极强
- ✅ 缠论实现质量高，是国内量化项目中缠论实现的标杆
- ✅ 附有同名书籍《量化交易之路》，学习资料丰富
- ✅ A股交易规则模拟完整，回测结果可信度高
- ✅ Stars极高，社区沉淀了大量策略讨论和使用经验

### 缺点

- ❌ **长时间未更新**，可能不兼容新版Python/依赖库
- ❌ GPL-3.0许可证具传染性，商业使用受严格限制
- ❌ 架构相对老旧，未采用现代Python异步/multiprocessing设计
- ❌ 性能瓶颈：大规模回测（全市场扫描）速度较慢
- ❌ 文档集中于书籍，在线文档不够系统

### 适用场景

- 个人投资者学习缠论/波浪理论的量化实现
- 策略初学者通过语义化框架快速上手
- 学术研究和教学演示（非商业用途）
- **注意**：如需商业使用，必须开源衍生代码

## 3. chan.py — 开放式缠论Python实现框架 🧊 冷门 ⭐ 缠论推荐

### 核心属性

| 属性 | 内容 |
|------|------|
| **GitHub** | [Qdriving/chan.py](https://github.com/Qdriving/chan.py) |
| **Stars** | ~300 |
| **许可证** | MIT |

### 核心功能

chan.py 是目前设计最现代的开放式缠论实现框架，将缠论形态学/动力学与机器学习结合：

- **形态学计算**：分型识别 → 笔的构建 → 线段划分 → 中枢识别 → 走势类型分类
- **动力学买卖点**：基于背驰/盘整背驰的精确买卖点（一买、二买、三买）生成
- **多级别联立**：支持多周期K线同时分析，实现区间套策略
- **机器学习打分**：使用 **XGBoost/LightGBM/MLP** 对缠论买卖点进行质量打分，过滤假信号
- **AutoML超参搜索**：自动搜索ML模型最优超参数
- **可视化绘图**：逐笔画出分型、笔、线段、中枢，一目了然
- **多数据源**：支持 akshare、baostock、futu（富途）三种行情数据源
- **实盘对接**：通过 Futu API 实现港股/美股程序化下单
- **数据持久化**：支持 MySQL 和 SQLite 存储历史分析结果

### 优点

- ✅ MIT许可证，商业使用友好，无传染性风险
- ✅ 架构现代，采用事件驱动设计，代码可读性高
- ✅ ML买卖点打分是独特创新，有效过滤假信号
- ✅ AutoML自动化超参搜索，降低ML调参门槛
- ✅ 多数据源+可视化+实盘，形成完整工具链
- ✅ 持续更新维护，社区响应积极

### 缺点

- ❌ Stars较少，社区规模有限，遇到问题可能缺少讨论
- ❌ 文档尚不完善，部分高级功能缺少使用示例
- ❌ 依赖较多（ML库+Futu SDK+数据���），安装配置有一定门槛
- ❌ 仅支持港股/美股实盘（Futu），A股实盘需自行对接
- ❌ ML打分模型需自行训练和更新，无预训练模型提供

### 适用场景

- 比起abu更推荐用于缠论研究和实盘应用（MIT vs GPL-3.0）
- 需要对缠论买卖点进行ML增强筛选的量化交易者
- 港股/美股交易者（通过Futu API实盘）
- 学术研究中需要高质量缠论开源实现作为baseline
