## 14. Backtrader 🔥 经典回测框架

| 属性 | 详情 |
|------|------|
| **GitHub** | https://github.com/mementum/backtrader |
| **Stars** | **17k** |
| **许可证** | MIT ✅ |
| **语言** | Python |

### 核心功能
- Python回测经典框架，API直观，50行代码即可跑一个策略
- 支持多数据源、多时间框架同时回测
- 集成TA-Lib技术指标库
- Plotly/matplotlib可视化
- 事件驱动架构

### ✅ 优点
1. **MIT许可证**：完全自由
2. **API直观**：Pythonic设计，学习成本最低
3. **社区成熟**：17k Stars，大量教程和示例
4. **多数据源**：CSV/Pandas/实时数据都能接
5. **文档完善**：官方文档非常详细

### ❌ 缺点
1. **性能一般**：事件驱动架构在大规模参数扫描时较慢
2. **作者已不再积极维护**：近年更新很少
3. **不支持向量化回测**：逐tick处理，不如vectorbt快
4. **实盘桥接需自己写**：框架不内置实盘接口

### 适用场景
- 快速验证单个因子/策略有效性
- 学习回测基本逻辑和最佳实践
- 不适合大规模参数优化

## 15. vectorbt 🔥 极速向量化回测

| 属性 | 详情 |
|------|------|
| **GitHub** | https://github.com/polakowo/vectorbt |
| **Stars** | ~4k |
| **许可证** | 需查看 |
| **语言** | Python |

### 核心功能
- **极速向量化回测**：基于NumPy+Numba，比Backtrader快100倍+
- 支持超大规模参数优化（百万级组合）
- Plotly交互式可视化
- 支持多资产组合回测
- 与Pandas无缝集成

### ✅ 优点
1. **性能极强**：向量化计算，百万级参数扫描几分钟搞定
2. **JIT加速**：Numba编译热点代码，接近C级性能
3. **交互式可视化**：Plotly图表可在浏览器交互
4. **Pandas友好**：数据格式和Pandas一致

### ❌ 缺点
1. **许可证需确认**：不是标准MIT/Apache
2. **只支持简单策略**：向量化回测不适合复杂的事件驱动策略
3. **学习曲线中等**：NumPy/Numba要求对向量化思维有理解
4. **社区较小**：4k Stars，不如Backtrader生态丰富

### 适用场景
- 大规模参数扫描和优化
- 简单技术指标策略的快速验证
- 需要跑百万级参数组合的场景

## 16. Zipline-reloaded — Quantopian维护版

| 属性 | 详情 |
|------|------|
| **GitHub** | https://github.com/stefan-jensen/zipline-reloaded |
| **Stars** | ~1k |
| **许可证** | Apache-2.0 ✅ |
| **语言** | Python |

### 核心功能
- Quantopian事件驱动回测框架的社区维护版
- 与pyfolio（绩效分析）/Alphalens（因子分析）等工具链配合
- 支持美股历史数据（ bundled data）
- 分钟级回测精度

### ✅ 优点
1. **Apache-2.0许可证**：较自由
2. **Quantopian遗产**：继承了当年最好的量化平台的回测引擎
3. **工具链完善**：pyfolio+Alphalens+empyrical完整生态
4. **分钟级精度**：比日级回测更精细

### ❌ 缺点
1. **美股为主**：A股数据需要自己适配
2. **社区小**：1k Stars，维护力度有限
3. **安装复杂**：依赖链较多，尤其 bundled data 安装耗时
4. **Quantopian已关闭**：原公司已倒闭，社区版维护靠志愿者

### 适用场景
- 美股策略的专业级回测（最佳选择）
- 因子分析（配合Alphalens）
- 绩效评估（配合pyfolio）

## 5. rqalpha 🔥

| 属性 | 详情 |
|------|------|
| **GitHub** | https://github.com/ricequant/rqalpha |
| **Stars** | ~6.6k |
| **许可证** | Apache-2.0 ✅ |
| **特点** | 米筐回测框架 |

### 核心功能
- 可扩展、可替换的算法回测与交易框架
- 支持多品种（股票、期货、基金等）
- 事件驱动架构
- 与 Ricequant 云端数据/实盘生态配合

### ✅ 优点
1. **Apache-2.0**：商用友好
2. **国产专业框架**：米筐出品，A股/期货支持好
3. **可扩展性强**：模块化设计
4. **实盘对接**：可对接券商/期货接口

### ❌ 缺点
1. **学习曲线**：比Backtrader复杂
2. **依赖米筐生态**：部分高级功能需要配合云端
3. **文档偏技术**：新手需要时间

### 适用场景
- A股/期货市场专业回测
- 需要与实盘对接的策略开发
- 机构投资者量化平台搭建
