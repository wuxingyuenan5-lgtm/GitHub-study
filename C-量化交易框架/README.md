## 11. VeighNa（vnpy）🔥 国内扛把子

| 属性 | 详情 |
|------|------|
| **GitHub** | https://github.com/vnpy/vnpy |
| **Stars** | **29.7k** |
| **许可证** | MIT ✅ |
| **语言** | Python |
| **版本** | 4.0（新增AI量化模块） |

### 核心功能
- **40+交易接口**：CTP（期货）/IB（美股）/OKX/币安（加密货币）/华鑫/通联等国内主流接口
- 内置CTA策略引擎、算法交易引擎、价差套利引擎、期权策略引擎(vnpy_optionmaster)
- 事件驱动架构，高性能
- GUI图形界面（基于PyQt）
- 4.0新增AI量化模块（LLM辅助策略开发）

### ✅ 优点
1. **MIT许可证**：完全自由商用
2. **国内接口最多**：40+交易接口，覆盖期货/股票/加密货币
3. **实盘能力最强**：真正能下单的框架，不是纯研究工具
4. **社区活跃**：29.7k Stars，国内量化圈子标配
5. **持续更新**：4.0版本2025年发布，保持迭代
6. **GUI界面**：不需要命令行，可视化操作
7. **生态完善**：vnpy_optionmaster/vnpy_scriptholder等模块化扩展

### ❌ 缺点
1. **学习曲线陡峭**：事件驱动架构+多引擎设计，新手上手需1-2周
2. **文档偏散**：官方文档组织不够系统，很多靠社区博客补充
3. **A股股票接口弱**：主要面向期货，股票实盘接口不如期货丰富
4. **代码风格较老**：部分模块代码还保留Python 2时代风格
5. **GUI依赖PyQt**：PyQt安装和许可证问题偶尔出现

### 适用场景
- 期货/加密货币实盘交易（最强选择）
- 需要对接国内券商/交易所的开发者
- 国内量化团队的基础框架

## 12. Qlib（微软）🔥 AI量化研究平台

| 属性 | 详情 |
|------|------|
| **GitHub** | https://github.com/microsoft/qlib |
| **Stars** | **17.5k** |
| **许可证** | MIT ✅ |
| **团队** | 微软亚洲研究院 |

### 核心功能
- AI量化投资平台，内置LightGBM/Transformer/LSTM/GRU/TabNet等模型
- 二进制高速数据存储（Qlib数据格式），支持A股历史数据
- 因子挖掘+模型训练+策略回测全流程
- Alpha158/Alpha360因子库内置
- 与RD-Agent深度集成（自动因子挖掘）

### ✅ 优点
1. **MIT许可证**：完全自由
2. **微软出品**：代码质量高，文档完善
3. **数据格式高效**：二进制存储，读取速度比CSV快10倍+
4. **模型丰富**：内置多种ML模型，可快速对比
5. **A股数据内置**：直接下载A股历史数据
6. **学术+工业双验证**：多篇论文+实际使用

### ❌ 缺点
1. **实盘支持弱**：更适合研究阶段，实盘交易需自己桥接
2. **数据更新不及时**：A股数据包需要手动下载更新
3. **因子库偏传统**：Alpha158/Alpha360是2017-2019年的因子，可能过时
4. **依赖链较重**：需要安装多个微软内部库
5. **文档偏技术**：面向研究者而非交易员

### 适用场景
- ML因子研究和模型训练
- 学术量化研究（最佳选择）
- 与RD-Agent配合做自动因子挖掘
- 不适合直接实盘交易

## 13. QUANTAXIS 🔥 全栈中文量化平台

| 属性 | 详情 |
|------|------|
| **GitHub** | https://github.com/yutiansut/QUANTAXIS |
| **Stars** | **8.7k** |
| **许可证** | MIT ✅ |

### 核心功能
- 全栈式中文量化平台：数据采集→存储(MongoDB)→回测→可视化→实盘
- 内置"策略工厂"模式
- 前端可视化界面（QUANTAXIS_WEB）
- 支持多种数据源和交易接口

### ✅ 优点
1. **MIT许可证**：完全自由
2. **中文原生**：文档、注释、社区都是中文
3. **全栈覆盖**：从数据到前端一应俱全
4. **MongoDB中台**：数据管理灵活

### ❌ 缺点
1. **近年更新放缓**：核心功能稳定但新功能少
2. **MongoDB门槛**：需要安装和维护MongoDB
3. **实盘能力中等**：不如VeighNa专业
4. **代码风格不一致**：多人协作导致风格混杂

### 适用场景
- 搭建自己的本地量化数据+回测平台
- 喜欢MongoDB数据管理方式
- 中文文档偏好者

## 6. OpenBB 🔥

| 属性 | 详情 |
|------|------|
| **GitHub** | https://github.com/OpenBB-finance/OpenBB |
| **Stars** | ~71k |
| **许可证** | AGPL-3.0 ⚠️ |
| **特点** | 开源数据平台 |

### 核心功能
- 面向分析师、量化研究员、AI Agent 的开源数据平台
- 整合多数据源
- 提供 Python SDK 和 API
- 支持股票、ETF、加密、宏观、货币等资产

### ✅ 优点
1. **71k Stars**：社区最大、生态最活跃
2. **为AI Agent设计**：原生支持 LLM/Agent 调用
3. **数据源丰富**：大量免费和付费数据扩展
4. **现代化架构**：相比旧版 OpenBB Terminal 更模块

### ❌ 缺点
1. **AGPL-3.0**：强传染性，商业使用受限
2. **A股覆盖有限**：主要面向美股和全球市场
3. **依赖外部数据源**：部分数据需要付费API

### 适用场景
- 构建AI投研 Agent 的数据底座
- 需要一站式金融数据平台
- 美股/全球市场研究
