## 1. AKShare ⭐

| 属性 | 详情 |
|------|------|
| GitHub | [akfamily/akshare](https://github.com/akfamily/akshare) |
| Stars | ~9k |
| 许可证 | MIT |

**核心功能**：A股/港股/期货/宏观/加密货币数据**免费全覆盖**。Python接口，数据源覆盖东方财富/同花顺/新浪/腾讯等多家平台，单一API调用即可获取行情/财务/资金流/板块/宏观等全维度数据。

✅ 优点：
- **覆盖面最广**：A股/港股/期货/宏观/加密货币，几乎无所不包
- ~9k Stars，中文量化社区使用率最高
- MIT许可证，商业友好
- 数据源多平台融合，单一接口获取多源数据
- 更新频繁，跟随市场变化及时
- 纯Python，安装简单（pip install akshare）

❌ 缺点：
- 数据来自爬虫，数据源变动时接口可能临时失效
- 无官方数据质量承诺，需自行校验
- 数据量大时爬取速度受限，不适合高频实时场景
- 接口命名规则不统一，学习成本较高
- 部分接口返回格式不稳定，版本升级可能breaking change

适用场景：**A股量化数据首选**，适合因子研究/回测数据获取/宏观分析等绝大多数量化数据需求。

## 3. FinanceToolkit 🧊 ⭐ 推荐关注

| 属性 | 详情 |
|------|------|
| GitHub | [JerBouma/FinanceToolkit](https://github.com/JerBouma/FinanceToolkit) |
| Stars | 5.2k |
| 许可证 | MIT |

**核心功能**：**130+财务指标计算**，全球市场覆盖。不仅能获取数据，更能直接计算DCF/EVA/WACC/Altman Z-Score等专业财务指标。还支持**MCP Server**模式，可直接嵌入WorkBuddy等AI工具使用！

✅ 优点：
- **130+财务指标**直接计算，不只是数据获取，更是财务分析工具
- 全球市场覆盖（美股/欧股/新兴市场等），A股以外的市场数据补充
- **MCP Server支持** — 可直接嵌入AI Agent使用，这是杀手级特性
- MIT许可证
- 代码质量高，结构清晰，文档专业
- 与FinanceDatabase配合，可获取大量公司基础数据

❌ 缺点：
- 🧊 冷门项目（相对AKShare而言），中文社区使用较少
- A股数据覆盖不如AKShare/adata深入
- 财务指标计算需要一定财务知识背景
- MCP Server功能尚属新特性，稳定性待验证

适用场景：**全球市场财务分析**；AI Agent集成场景（MCP Server）；需要专业财务指标计算（DCF/估值/信用评分）的投研工作。

- 需要自行评估论文质量和代码可用性

## 6. a-stock-data ⭐

| 属性 | 详情 |
|------|------|
| **GitHub** | https://github.com/simonlin1212/a-stock-data |
| **Stars** | 未显示 |
| **许可证** | Apache-2.0 |
| **特点** | A股全栈数据工具包（AI编程助手友好） |

### 核心功能
- 10层架构、44个端点、15个数据源、零鉴权
- 行情层：K线、五档盘口、实时报价、PE/PB/市值、指数/ETF
- 研报层：个股/行业研报、PDF下载、一致预期、自然语言研报搜索
- 信号层：强势股、题材归因、北向资金、板块归属、资金流向、龙虎榜
- 资金面/筹码层：融资融券、大宗交易、股东户数、分红送转、120日资金流
- 新闻层：个股新闻、财联社电报、全球资讯
- 打板层：涨停池、炸板池、跌停池、连板梯队、涨停原因
- ETF期权层：合约清单、T型报价、希腊字母、隐含波动率
- 备用源降级：官方交易所、新浪、HKEX等独立备胎接口

### ✅ 优点
1. **A股数据覆盖极广**：从行情到研报到资金面到打板到期权，几乎全覆盖
2. **零鉴权**：大部分接口无需API Key，即拿即用
3. **AI编程助手友好**：封装为Markdown Skill文件，Claude Code/Codex可直接调用
4. **备用降级**：主源失效时有备胎接口
5. **Apache-2.0许可证**：商用较自由

### ❌ 缺点
1. **数据源依赖免费接口**：稳定性和数据质量需自行校验
2. **项目较新**：Stars未显示，维护持续性待观察
3. **接口数量多**：学习成本高，需要花时间熟悉
4. **合规风险**：部分数据源（如iwencai语义搜索）可能有使用限制

### 适用场景
- 配合AI编程助手做A股量化研究
- 需要一站式A股数据且不想申请多个API Key
- 快速搭建A股投研数据管道

- 国债收益率曲线、CFTC COT、Nasdaq财报日历
- 实时行情、K线、基本面、资金流向、技术指标

5. **Apache-2.0许可证**：商用较自由

### ❌ 缺点
1. **商业使用需谨慎**：按合规等级标注数据源，Tier C（CBOE、Yahoo等）需授权或仅限个人
2. **项目较新**：Stars未显示，维护持续性待观察
3. **港股覆盖相对美股弱**：主要优势在美股

### 适用场景
- 美股量化研究，尤其是期权、做空、财报数据

- 需要免费获取专业美股数据的场景

## 8. free-stockdb ⭐

| 属性 | 详情 |
|------|------|
| **GitHub** | https://github.com/hello245m/free-stockdb |
| **Stars** | 未显示 |
| **许可证** | MIT |
| **特点** | 本地A股量化数据引擎 |

### 核心功能
- 面向A股日K、分钟K、ETF分钟、tick级数据的本地量化引擎
- 增量同步、本地缓存、复权、批量查询、回测与指标计算
- 39种技术指标、5种指数计算方法
- 五种调用方式：Python SDK、HTTP API、Excel/WPS、HTML页面、AI MCP
- C++时序引擎，Rust计算核心，比pandas快3倍
- 数据本地落盘，离线可继续查询回测

### ✅ 优点
1. **本地优先**：数据落盘，不受远程API限频/封号影响
2. **全市场回测友好**：7000+股票分钟线回测从几天缩短到数秒
3. **五种调用方式**：满足不同使用习惯，支持MCP嵌入AI工具
4. **MIT许可证**：完全自由
5. **增量同步**：只处理变化数据，节省带宽和时间

### ❌ 缺点
1. **Windows为主**：目前主要提供Windows发行包，mac/Linux版本待发布
2. **数据源可控但需配置**：需要自己维护同步节点或数据源
3. **项目较新**：成熟度和大规模使用验证待观察
4. **磁盘占用**：全量分钟线约20GB

### 适用场景
- 需要高频/全市场回测，对数据获取速度敏感
- 希望数据本地化，避免依赖远程API
- 想用AI工具（MCP）直接查询本地行情和指标
