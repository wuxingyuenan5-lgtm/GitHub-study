## 6. RD-Agent-Quant（微软）⭐ 强烈推荐

| 属性 | 详情 |
|------|------|
| **GitHub** | https://github.com/microsoft/RD-Agent |
| **Stars** | ~5k |
| **许可证** | MIT ✅ |
| **团队** | 微软亚洲研究院（MSRA） |
| **论文** | NeurIPS 2025 接收 |

### 核心功能
- **自动化因子挖掘+模型优化全闭环**：假设生成→代码实现→回测验证→反馈分析→自动迭代
- **Co-STEER代码智能体**：从通用数据科学经验→领域特定经验进化
- **Thompson采样自适应方向选择**：智能选择下一步挖掘方向，避免盲目搜索
- **因子减少70%但IC和ARR反而提升**：IC约0.053，ARR约14.21%
- **端到端成本低于10美元**

### ✅ 优点
1. **微软出品+顶会论文**：学术和实践双重验证，代码质量高
2. **MIT许可证**：完全自由商用
3. **真正的自动化闭环**：不是手动挖因子，而是AI自动假设→实现→验证→迭代
4. **成本极低**：低于10美元就能跑完一轮因子挖掘
5. **效果实证**：因子减少70%但性能提升，说明挖出了真正有效的因子
6. **可扩展性强**：不仅限于金融，任何数据驱动的R&D场景都适用

### ❌ 缺点
1. **依赖Qlib框架**：需要熟悉微软Qlib的数据格式和回测逻辑
2. **主要针对美股**：A股适配需要自己改数据源
3. **LLM调用频繁**：闭环迭代需要多次LLM调用，API成本虽低但不是零
4. **文档偏学术**：README写得比较技术化，上手门槛比纯工具类项目高
5. **部署复杂度中等**：需要同时搭Qlib+RD-Agent环境

### 适用场景
- 有数据但缺因子，想让AI自动挖因子并持续优化
- 量化研究团队需要自动化因子生产线
- 学习LLM+量化融合的最佳实践

## 7. GuruAgents 🧊 冷门学术

| 属性 | 详情 |
|------|------|
| **GitHub** | https://github.com/yejining99/GuruAgents |
| **Stars** | <50 |
| **许可证** | 未标注 |

### 核心功能
- **5个投资大师Agent**：巴菲特/格雷厄姆/Piotroski/其他价值投资先驱
- **Prompt工程量化大师哲学**：把大师投资理念编码为LLM指令+确定性推理管线
- **NASDAQ-100回测**：巴菲特Agent CAGR 42.2%
- **不同流派对比**：看各大师对同一标的的分歧和共识

### ✅ 优点
1. **投资哲学量化**：把抽象的投资理念转化为可执行的LLM指令，有创意
2. **实证回测**：巴菲特Agent42.2% CAGR说明prompt编码确实能捕捉到价值投资特征
3. **流派对比**：不同大师Agent的分歧和共识提供了投资决策的多视角参考
4. **学术严谨**：确定性推理管线而非纯prompt猜测，方法论清晰

### ❌ 缺点
1. **许可证未标注**：商用有风险
2. **大师数量少**：只有5个，缺少成长/趋势/量化等流派
3. **回测可能过拟合**：42.2% CAGR在NASDAQ-100上很优秀，但可能是特定时段的特征
4. **缺少A股适配**：NASDAQ-100数据，A股需要自己改
5. **社区极小**：<50 Stars，几乎无维护

### 适用场景
- 研究不同投资流派的可量化实现方法
- 学习如何用Prompt工程编码专家知识
- 价值投资策略开发参考

## 10. ValueCell 🧊 冷门创新

| 属性 | 详情 |
|------|------|
| **GitHub** | https://github.com/ValueCell-ai/valuecell |
| **Stars** | ~500 |
| **许可证** | 未标注 |

### 核心功能
- 巴菲特/芒格等大师策略编码为独立Agent辩论
- Orchestrator+Clients协同架构
- A2A协议（Agent-to-Agent）支持跨Agent通信
- AutoTradeAgent模拟真实交易环境

### ✅ 优点
1. **A2A协议创新**：支持Agent间直接通信，比传统prompt链路更灵活
2. **辩论机制**：不同流派Agent辩论产生共识，比单一Agent更全面
3. **AutoTradeAgent**：模拟真实交易环境（含滑点、手续费），比纯回测更接近实盘
4. **架构模块化**：Orchestrator+Clients分离，易于扩展新Agent

### ❌ 缺点
1. **许可证未标注**：商用有风险
2. **文档不够完善**：500 Stars但README较简
3. **主要面向美股**：A股需要适配
4. **辩论质量依赖LLM**：弱模型下辩论可能变成"两方都瞎说"

### 适用场景
- 看不同投资流派对同一标的的分歧和共识
- 学习A2A协议在金融Agent中的应用
- 模拟交易环境下的策略验证
