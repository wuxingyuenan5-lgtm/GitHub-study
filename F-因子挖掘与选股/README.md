## 2. AlphaAgent 🧊

| 属性 | 详情 |
|------|------|
| GitHub | [RndmVariableQ/AlphaAgent](https://github.com/RndmVariableQ/AlphaAgent) |
| Stars | 学术级 |
| 许可证 | — |
| 学术背景 | KDD 2025 论文代码 |

**核心功能**：3个专门Agent协同挖掘Alpha因子——**想法Agent**生成因子假设、**因子Agent**将假设转化为可执行代码、**评估Agent**回测验证并筛选入库。全流程自动化：生成 → 回测 → 筛选，形成因子挖掘闭环。

✅ 优点：
- 专业化Agent分工，每个Agent职责清晰，避免单模型"一人多职"导致的输出混乱
- 自动化程度高，从因子构思到代码实现再到评估全链路自动完成
- 有KDD 2025顶会论文背书，方法论经过学术验证

❌ 缺点：
- 学术项目，代码工程化程度有限，直接用于生产需大量改造
- 社区活跃度低，issue/PR响应可能不及时
- 因子池质量受LLM生成能力限制，可能产出大量无效因子

适用场景：**因子挖掘研究**，适合量化研究员探索新因子思路，或作为因子生产线的灵感生成环节。

## 3. MCTS-LLM-Alpha 🧊

| 属性 | 详情 |
|------|------|
| GitHub | [dtbtc/mcts-llm-alpha](https://github.com/dtbtc/mcts-llm-alpha) |
| Stars | 极冷门 |
| 许可证 | — |
| 学术背景 | — |

**核心功能**：将**蒙特卡洛树搜索（MCTS）**与LLM结合，搜索并挖掘公式化Alpha因子。核心亮点是**五维评估体系**：有效性、稳定性、换手率、多样性、过拟合，全面量化因子质量而非仅看收益。

✅ 优点：
- MCTS提供结构化搜索策略，比纯LLM随机生成更有方向性
- 五维评估体系是亮点，兼顾因子质量的多维度考量
- 公式化因子可解释性强，能直接理解因子逻辑

❌ 缺点：
- 极冷门项目，文档和社区支持几乎为零
- MCTS搜索空间大，计算开销较高
- 搜索效率受LLM质量影响，低质量LLM可能产出大量低效分支

适用场景：**学术研究**，适合对因子评估维度有深入需求的量化研究者，或对MCTS+LLM组合方法感兴趣的研究者。

## 4. aifa-quant ⭐ 强烈推荐

| 属性 | 详情 |
|------|------|
| GitHub | [Hanzhi0807/aifa-quant](https://github.com/Hanzhi0807/aifa-quant) |
| Stars | ~1k |
| 许可证 | — |

**核心功能**：AI选股系统，最突出的特点是**SHAP可解释性**——让你清楚模型在看什么因子。支持**5种投资者Profile**（激进/均衡/稳健/成长/价值），因子覆盖**技术面+Alpha101+基本面+宏观+情绪**五维，模型采用LightGBM/LambdaRank/XGBoost，风控层包含ATR止损+市场体制过滤+行业集中度上限。本地DuckDB存储数据。

✅ 优点：
- **SHAP可解释性**是最大亮点，黑盒变白盒，适合需要向投委会/合规解释模型决策的场景
- 5种投资者Profile适配不同风险偏好，实用性强
- 多层风控设计（ATR止损+体制过滤+行业约束），不是"裸跑"模型
- 因子维度全面（技术+Alpha101+基本面+宏观+情绪），覆盖面广
- DuckDB本地存储，无需外部数据库依赖，部署简单

❌ 缺点：
- Stars ~1k，社区规模中等，长期维护有一定不确定性
- 选股结果依赖因子池质量，极端市场环境下可能表现不佳
- 缺少实盘对接模块，需自行桥接交易执行层

适用场景：**AI选股研究与实践**，特别适合需要可解释性的机构/个人投资者；5种Profile适合不同投资风格用户快速上手。

## 5. AlphaGen 🧊

| 属性 | 详情 |
|------|------|
| GitHub | [RL-MLDM/alphagen](https://github.com/RL-MLDM/alphagen) |
| Stars | 学术级 |
| 许可证 | — |
| 学术背景 | — |

**核心功能**：用**强化学习（RL）**自动生成**协同的Alpha因子组合**。核心思路：不是逐个挖掘单个因子，而是挖掘能**协同工作**的因子集合——关注因子间的互补性和冗余性，直接优化组合IC。

✅ 优点：
- 创新思路：因子组合协同性而非单因子有效性，更贴近实际使用场景
- RL框架理论上可以持续探索更优因子组合
- 减少因子冗余，提升组合整体表现

❌ 缺点：
- 学术项目，工程化程度低
- RL训练不稳定，因子组合质量波动大
- 社区极小，几乎无外部支持
- 训练时间长，计算资源需求较高

适用场景：**因子组合优化研究**，适合已有多因子池但需要优化组合协同性的研究者。

## 6. alpha-gfn 🧊

| 属性 | 详情 |
|------|------|
| GitHub | [nshen7/alpha-gfn](https://github.com/nshen7/alpha-gfn) |
| Stars | 极冷门 |
| 许可证 | — |
| 学术背景 | — |

**核心功能**：用**生成流网络（GFlowNet）**挖掘Alpha因子。GFlowNet是深度强化学习的一种新框架，能以与奖励成比例的概率采样多种不同因子，天然支持多样性输出。

✅ 优点：
- GFlowNet天然支持多样因子生成，避免RL只收敛到单一最优解
- 理论框架新颖，学术价值高
- 生成过程可控，可调节多样性-质量平衡

❌ 缺点：
- 极冷门项目，使用者极少
- GFlowNet本身尚属前沿研究，工程稳定性不足
- 因子表达式搜索空间定义需要专业知识
- 无回测/实盘对接，纯学术探索

适用场景：**前沿学术探索**，适合对GFlowNet+量化交叉方向感兴趣的研究者，不适合直接用于生产。
